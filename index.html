Hubungkan ke Google Spreadsheet Anda

Aplikasi ini terhubung langsung ke Google Spreadsheet menggunakan backend Google Apps Script gratis tanpa batas.

Dapatkan URL ini saat melakukan Deploy -> Web App di Google Spreadsheet.

Nama ini akan dicetak otomatis di bagian tanda tangan kuitansi pembayaran.

PIN digunakan untuk masuk ke dashboard admin dari tampilan awal.

Cara Menyiapkan Google Spreadsheet (Hanya 3 Menit)

1. Buat Spreadsheet
Buka sheets.new di browser Anda dan beri nama DB_Pembayaran_MI.
2. Salin Script Code.gs
Klik menu Ekstensi > Apps Script, lalu tempelkan kode yang ada di file google-apps-script/Code.gs.
3. Inisialisasi Sheet
Pilih fungsi initSheets di bagian atas editor lalu klik Jalankan untuk membuat seluruh tabel otomatis.
4. Deploy Web App
Klik Terapkan > Penerapan baru > Aplikasi Web. Pilih akses: "Siapa saja". Salin URL-nya ke kolom di atas!
